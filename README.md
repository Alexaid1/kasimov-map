# Касимов: интерактивная карта наследия

Карта исторического центра Касимова: границы исследования (округ, историческое поселение по Приказу
Минкультуры № 2969, граница проекта между оврагами), ОКН и ценные градоформирующие объекты, этажность,
ценности и проблемы.

**Карта:** https://alexaid1.github.io/kasimov-map/

На карте можно:
- включать и выключать слои;
- фильтровать объекты по категории, территории, точности привязки и искать по названию или адресу;
- отбирать здания по этажности и году постройки;
- выгружать отобранное в CSV (открывается в Excel) или GeoJSON (открывается в QGIS). Галочка
  «только в видимой области» ограничивает выгрузку тем, что сейчас видно на экране.

Текущий вид карты и включённые слои сохраняются в адресе страницы, так что ссылку можно переслать.

## Как обновить данные

```
python export_web.py          # пересобирает docs/data/*.geojson
git add -A
git commit -m "Обновление данных"
git push                      # через 1–2 минуты карта обновится
```

Что где править (локально, в репозиторий не входит):
- `data/objects_geocoded.csv` — объекты наследия: название, адрес, категория, координаты `lat`, `lon`;
- `data/mkd_geocoded.csv` — реестр МКД: этажность, год, координаты;
- `data/ovragi.gpkg` — контуры оврагов (правится в QGIS);
- `make_maps.py` — списки доминант, площадей, улиц (`DOMINANTS`, `SQUARES`, `PROTECTED_STREETS`),
  точки «проверить на месте» (`VERIFY`).

`make_maps.py` строит статичные карты для слайдов, `export_web.py` берёт те же расчёты для сайта.

## Источники

Приказ Минкультуры России № 2969 от 07.12.2015; ЕГРОКН (opendata.mkrf.ru); OpenStreetMap;
реестр МКД (dom.mingkh.ru).
