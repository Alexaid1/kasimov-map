# Касимов: интерактивная карта наследия

Карта исторического центра Касимова: границы исследования (округ, историческое поселение по Приказу
Минкультуры № 2969, граница проекта между оврагами), ОКН и ценные градоформирующие объекты, этажность,
ценности и проблемы.

**Карта:** https://alexaid1.github.io/kasimov-map/

На карте можно:
- смотреть контур и карточку каждого здания города (≈13 тыс.): адрес, тип, этажность, год или период,
  объект наследия, материал, состояние — с источником каждого значения; раскрашивать здания по
  заполненности данных, этажности, году, типу; находить здания без адреса, этажности или года;
- включать и выключать слои;
- фильтровать объекты по категории, территории, точности привязки и искать по названию или адресу;
- отбирать здания по этажности и году постройки;
- выгружать отобранное в CSV (открывается в Excel) или GeoJSON (открывается в QGIS). Галочка
  «только в видимой области» ограничивает выгрузку тем, что сейчас видно на экране.

Текущий вид карты и включённые слои сохраняются в адресе страницы, так что ссылку можно переслать.

## Как обновить данные

```
python export_web.py          # пересобирает docs/data/*.geojson
git add -A
git commit -m "Обновление данных"
git push                      # через 1–2 минуты карта обновится
```

### База зданий

Контуры — Overture Maps: здания OSM + Microsoft ML Buildings (распознаны по спутниковым снимкам);
кэш `data/overture_buildings.parquet`. Автоматически к зданию подтягиваются OSM (адрес, тип, этажность),
реестр МКД (этажность, год), Приказ № 2969 / ЕГРОКН (объект наследия, период постройки).

Сведения ЕГРН (публичная кадастровая карта nspd.gov.ru) собирает `python nspd.py`: по земельным
участкам — адрес и разрешённое использование (адрес получают все дома на участке), по зарегистрированным
зданиям — назначение, этажность, год постройки, материал стен, кадастровый №. Запросы идут медленно,
с паузой; кэш `data/nspd_raw.jsonl`, прерванный запуск продолжается с места остановки.

Ручные дополнения — `data/buildings_info.csv` (разделитель «;», открывается в Excel):

| bid | address | type | levels | year | period | material | condition | use | notes | photo | source | checked |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

`bid` — ID здания: кнопка «ID» в карточке на карте копирует его. Заполненные поля перекрывают
автоматические. Заполненность карточки считается по 6 полям: адрес, тип, этажность, год/период,
материал, состояние.

Что где править (локально, в репозиторий не входит):
- `data/buildings_info.csv` — ручные данные по зданиям (см. выше);
- `data/objects_geocoded.csv` — объекты наследия: название, адрес, категория, координаты `lat`, `lon`;
- `data/mkd_geocoded.csv` — реестр МКД: этажность, год, координаты;
- `data/ovragi.gpkg` — контуры оврагов (правится в QGIS);
- `make_maps.py` — списки доминант, площадей, улиц (`DOMINANTS`, `SQUARES`, `PROTECTED_STREETS`),
  точки «проверить на месте» (`VERIFY`).

`make_maps.py` строит статичные карты для слайдов, `export_web.py` берёт те же расчёты для сайта.

## Источники
